# Braver Flutter UI

Braver Flutter UI is a comprehensive design system and component library for building consistent, accessible healthcare applications. It provides a cohesive set of widgets and design tokens that work together to create beautiful, functional user interfaces.

## Key Features

  <Card title="Design Tokens" icon="palette">

  <Card title="Dark Mode" icon="moon">

## Architecture

The library is organized into two main areas:

### Components

Reusable Flutter widgets organized by category:

- **Buttons** - Primary, secondary, link, menu, navigation buttons
- **Forms** - Text inputs, date/time pickers, dropdowns, checkboxes
- **Lists** - List items, tappable items, empty states
- **Avatars** - User avatars, folder avatars, text-based avatars
- **Modals** - Dialogs, confirmation prompts, consent flows
- **Indicators** - Loading states, badges, notification pins
- **Layout** - Tabs, menus, containers

### Design Tokens

Centralized design values that ensure consistency:

- **Colors** - Background, text, tint, border, and accent colors
- **Typography** - Font families, sizes, weights, and text styles
- **Spacing** - Consistent spacing scale for margins and padding
- **Borders** - Border widths, radii, and styles
- **Shadows** - Elevation and shadow definitions
- **Animation** - Durations and easing curves
