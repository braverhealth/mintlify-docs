An animated loading spinner used to indicate async operations, loading states, or processing. Adapts to platform conventions.

## Examples

### Basic Loading Indicator

```dart
LoadingIndicator()
```

### Custom Size

```dart
LoadingIndicator(size: 48.0)
```

### In Button

```dart
PrimaryButton(
  text: 'Submitting...',
  isLoading: true,
  onPressed: null,
)
```

### Full Screen Loading

```dart
Center(
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: [
      LoadingIndicator(size: 48.0),
      SizedBox(height: 16),
      Text('Loading...'),
    ],
  ),
)
```

### In List

```dart
if (isLoading)
  Center(
    child: Padding(
      padding: EdgeInsets.all(16),
      child: LoadingIndicator(),
    ),
  )
```

## Usage Patterns

### Async Operation

```dart
Widget build(BuildContext context) {
  if (state.isLoading) {
    return Center(child: LoadingIndicator());
  }
  return Content();
}
```

### Pull to Refresh

```dart
RefreshIndicator(
  onRefresh: () => refreshData(),
  child: listView,
)
```

### Button Loading State

```dart
PrimaryButton(
  text: isSubmitting ? 'Saving...' : 'Save',
  isLoading: isSubmitting,
  onPressed: isSubmitting ? null : () => save(),
)
```

### Overlay

```dart
Stack(
  children: [
    Content(),
    if (isLoading)
      Container(
        color: Colors.black45,
        child: Center(child: LoadingIndicator(size: 48)),
      ),
  ],
)
```
