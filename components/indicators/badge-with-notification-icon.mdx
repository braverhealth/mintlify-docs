An icon widget that displays a notification badge overlay. Used to show activity status or counts on icons in navigation, toolbars, or action buttons.

## Examples

### Basic Usage

```dart
BadgeWithNotificationIcon(
  iconName: SvgIconName.bell,
  hasActivity: hasNotifications,
)
```

### With Count

```dart
CountBadge.withIcon(
  icon: SvgIcon(SvgIconName.mail, SvgIconSize.medium),
  iconSize: Size(24, 24),
  badge: CountBadge.unread(count: unreadCount),
)
```

### In Navigation

```dart
NavButton(
  iconName: SvgIconName.inbox,
  semanticLabel: S.of(context).inboxButton,
  onPressed: () => openInbox(),
  child: BadgeWithNotificationIcon(
    iconName: SvgIconName.inbox,
    hasActivity: hasUnreadMessages,
  ),
)
```

### In Tab Bar

```dart
BraverTab(
  text: 'Messages',
  index: 1,
  controller: tabController,
  icon: SvgIcon(SvgIconName.mail, SvgIconSize.small),
  activityCount: unreadCount,
)
```

## Parameters

<ResponseField name="iconName" type="SvgIconName" required>
  The icon to display.
</ResponseField>

<ResponseField name="hasActivity" type="bool" required>
  Whether to show the notification badge.
</ResponseField>

<ResponseField name="iconSize" type="SvgIconSize">
  Size of the icon. Default: `SvgIconSize.medium`.
</ResponseField>

<ResponseField name="iconColor" type="SvgIconColor">
  Color of the icon. Default: `SvgIconColor.normal`.
</ResponseField>

## Use Cases

### Tab Navigation

```dart
Row(
  children: [
    BadgeWithNotificationIcon(
      iconName: SvgIconName.home,
      hasActivity: false,
    ),
    BadgeWithNotificationIcon(
      iconName: SvgIconName.mail,
      hasActivity: hasUnread,
    ),
    BadgeWithNotificationIcon(
      iconName: SvgIconName.settings,
      hasActivity: hasNewSettings,
    ),
  ],
)
```

### Toolbar Action

```dart
HudButton(
  semanticLabel: S.of(context).notificationsButton,
  onTap: () => showNotifications(),
  child: BadgeWithNotificationIcon(
    iconName: SvgIconName.bell,
    hasActivity: hasNotifications,
  ),
)
```
