A small colored indicator dot used to show notification status, unread counts, or activity indicators. Commonly used alongside icons, avatars, or list items.

## Examples

### Basic Notification Pin

```dart
NotificationPin()
```

### With Count Badge

```dart
CountBadge(count: 5)
```

### As Activity Indicator

```dart
ActivityIndicatorIcon(hasActivity: hasUnread)
```

### In List Item

```dart
ListItem(
  title: 'Team Discussion',
  subtitle: 'Latest updates',
  subtitleLeading: NotificationPin(),
)
```

## Variants

| Component | Description |
|-----------|-------------|
| `NotificationPin` | Simple dot indicator |
| `CountBadge` | Numeric count display |
| `CountBadge.dot()` | Alternative dot style |
| `CountBadge.unread()` | Red/orange unread badge |
| `ActivityIndicatorIcon` | Conditional activity dot |

## Usage Patterns

### Conditional Display

```dart
if (hasNotifications)
  NotificationPin()
```

### In Tab Bar

```dart
BraverTab(
  text: 'Inbox',
  index: 0,
  controller: tabController,
  activityCount: unreadCount,
)
```

### In Avatar Overlay

```dart
Avatar(
  subject: userSubject,
  overlayWidget: Positioned(
    bottom: 0,
    right: 0,
    child: NotificationPin(),
  ),
)
```
