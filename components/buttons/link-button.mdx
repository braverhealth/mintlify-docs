## Features

<CardGroup cols={2}>
  <Card title="Hyperlink Styling">
    Minimal visual prominence while remaining interactive
  </Card>
  <Card title="Tinted or Plain">
    Control color via `tinted` parameter
  </Card>
  <Card title="Optional Underline">
    Add text decoration via `underline` parameter
  </Card>
  <Card title="Icon Support">
    Display icon before or after text
  </Card>
</CardGroup>

## Examples

### Basic Link Button

```dart
LinkButton(
  text: 'Learn more',
  onPressed: () => openLink(),
)
```

### With Underline

```dart
LinkButton(
  text: 'View details',
  underline: true,
  onPressed: () => showDetails(),
)
```

### With Icon

```dart
LinkButton(
  text: 'Open in browser',
  iconName: SvgIconName.externalLink,
  iconPosition: IconPosition.end,
  onPressed: () => openBrowser(),
)
```

### Icon-only Link

```dart
LinkButton(
  iconName: SvgIconName.help,
  semanticLabel: S.of(context).helpButton,
  onPressed: () => showHelp(),
)
```

```dart
LinkButton(
  text: 'Skip',
  tinted: false,
  onPressed: () => skipStep(),
)
```

## Parameters

<ResponseField name="text" type="String?">
  Button label text. Required unless using icon-only mode.
</ResponseField>

<ResponseField name="iconName" type="SvgIconName?">
  Optional icon to display.
</ResponseField>

<ResponseField name="tinted" type="bool">
  Whether to use tinted (brand color) text. Default: `true`.
</ResponseField>

<ResponseField name="underline" type="bool">
  Whether to add text underline. Default: `false`.
</ResponseField>

<ResponseField name="iconPosition" type="IconPosition">
  Position of icon relative to text. Default: `start`.
</ResponseField>

<ResponseField name="onPressed" type="VoidCallback?">
  Callback when button is pressed. Set to `null` to disable.
</ResponseField>

<ResponseField name="semanticLabel" type="String?">
  Accessibility label for screen readers.
</ResponseField>
