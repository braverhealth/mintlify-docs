Displays different button styles based on its `isEnabled` state. When enabled, shows as a PrimaryButton. When disabled, shows as a SecondaryButton.transparent with a larger icon.

## Variants

| Variant | Description |
|---------|-------------|
| `ToggleButton.text` | Toggle button with text label |
| `ToggleButton.icon` | Toggle button with icon only |

## Features

<CardGroup cols={2}>
  <Card title="State-based Styling">
    Automatically switches appearance based on `isEnabled`
  </Card>
  <Card title="Customizable Size">
    Supports all button sizes
  </Card>
  <Card title="Icon or Text">
    Display either icon or text content
  </Card>
  <Card title="Semantic Labels">
    Supports accessibility labels
  </Card>
</CardGroup>

## Examples

### Text Toggle Button

```dart
ToggleButton.text(
  text: 'Notifications',
  isEnabled: notificationsEnabled,
  size: ButtonSize.medium,
  onPressed: () => toggleNotifications(),
)
```

### Icon Toggle Button

```dart
ToggleButton.icon(
  iconName: SvgIconName.bell,
  isEnabled: notificationsEnabled,
  size: ButtonSize.medium,
  semanticLabel: S.of(context).toggleNotificationsButton,
  onPressed: () => toggleNotifications(),
)
```

### Large Toggle Button

```dart
ToggleButton.icon(
  iconName: SvgIconName.microphone,
  isEnabled: isMuted,
  size: ButtonSize.large,
  semanticLabel: S.of(context).toggleMuteButton,
  onPressed: () => toggleMute(),
)
```

## State Behavior

| State | Appearance |
|-------|------------|
| `isEnabled: true` | PrimaryButton styling (filled, prominent) |
| `isEnabled: false` | SecondaryButton.transparent (subtle, larger icon) |
