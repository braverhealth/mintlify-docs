A circular or square avatar widget that displays user/subject information. Renders either a cached network image or a colored background with initials.

## Features

<CardGroup cols={2}>
  <Card title="Image Support">
    Displays cached network images with automatic size variants
  </Card>
  <Card title="Fallback Display">
    Shows colored background with initials when no image
  </Card>
  <Card title="Flexible Sizing">
    Supports custom sizes with adaptive scaling
  </Card>
  <Card title="Shape Options">
    Circular (default) or square
  </Card>
</CardGroup>

## Examples

### Basic Avatar

```dart
Avatar(
  subject: userSubject,
  size: 48.0,
)
```

### Large Avatar

```dart
Avatar(
  subject: userSubject,
  size: 120.0,
  textSize: TextSize.large,
)
```

### Square Avatar

```dart
Avatar(
  subject: userSubject,
  isSquare: true,
  size: 64.0,
)
```

### With Overlay

```dart
Avatar(
  subject: userSubject,
  size: 48.0,
  overlayWidget: Positioned(
    bottom: 0,
    right: 0,
    child: NotificationPin(),
  ),
)
```

### Single Letter Display

```dart
Avatar(
  subject: userSubject,
  singleLetter: true,
)
```

### Mega Avatar

```dart
Avatar(
  subject: userSubject,
  size: 120.0,
  mega: true,
)
```

## Parameters

<ResponseField name="subject" type="AvatarSubject" required>
  The subject (user, contact, etc.) whose information is displayed.
</ResponseField>

<ResponseField name="size" type="double">
  Size of the avatar in logical pixels. Default: `48.0`.
</ResponseField>

<ResponseField name="textSize" type="TextSize">
  Size of the initials text. Default: `TextSize.large`.
</ResponseField>

<ResponseField name="singleLetter" type="bool">
  Display only a single letter instead of two initials. Default: `false`.
</ResponseField>

<ResponseField name="mega" type="bool">
  Use mega/large text styling. Default: `false`.
</ResponseField>

<ResponseField name="isSquare" type="bool">
  Avatar should be square instead of circular. Default: `false`.
</ResponseField>

<ResponseField name="overlayWidget" type="Widget?">
  Optional widget to overlay on top of the avatar.
</ResponseField>

<ResponseField name="colorOverride" type="Color?">
  Optional color override for the avatar background.
</ResponseField>

<ResponseField name="enableRepaintBoundary" type="bool">
  Enable caching for list performance. Default: `true`.
</ResponseField>

## AvatarSubject

The `AvatarSubject` provides information for avatar rendering:

```dart
AvatarSubject(
  initials: 'JD',
  colorIndex: 0,
  imageUrl: 'https://example.com/avatar.jpg',
)
```
