A widget that manages the display of modals and dialogs in the application. It's the root container for all modal interactions, managing multiple modal layers with animations, positioning, and lifecycle management.

## Features

<CardGroup cols={2}>
  <Card title="Multi-layer System">
    Support simultaneous display of different modal types
  </Card>
  <Card title="Responsive Layout">
    Adapts for wide and narrow layouts automatically
  </Card>
  <Card title="Smooth Animations">
    Configurable appearance/disappearance transitions
  </Card>
  <Card title="Lifecycle Management">
    Showing, hiding, and dismissing with callbacks
  </Card>
</CardGroup>

## Modal Types

| Type | Description | Use Case |
|------|-------------|----------|
| `Dialog` | Centered modal | Confirmations, user input |
| `Menu` | Context menu | Actions positioned near trigger |
| `Page` | Full-screen modal | Complex content, forms |
| `Toast` | Non-blocking notification | Status messages |
| `Gallery` | Full-screen overlay | Image/content galleries |
| `Peek` | Side panel | Wide layout additional content |
| `BlockUI` | Blocking overlay | Loading states |

## Setup

Wrap your app with ModalSurface:

```dart
ModalSurface(
  isWideLayout: isWideLayout,
  isCaregiverApp: false,
  child: MyApp(),
)
```

## Showing Modals

Access the modal surface and show different modal types:

```dart
final modalSurface = ModalSurface.of(context);

// Show a dialog
modalSurface.showDialog(MyConfirmationDialog());

// Show a context menu
modalSurface.showMenu(
  MyContextMenu(),
  context, // position relative to this widget
);

// Show a full-screen page
modalSurface.showPage(MyFormPage());

// Show a toast notification
modalSurface.showToast(
  Toast.success(message: 'Saved successfully'),
);

// Show a side panel (wide layouts only)
modalSurface.showPeek(MySidePanel());

// Show full-screen gallery
modalSurface.showGallery(ImageGallery(images: images));

// Block UI with loading indicator
modalSurface.blockUI(LoadingIndicator());
```

## Hiding Modals

```dart
final modalSurface = ModalSurface.of(context);

// Hide specific modal types
modalSurface.hideDialog();
modalSurface.hideMenu();
modalSurface.hidePage();
modalSurface.hidePeek();
modalSurface.hideGallery();
modalSurface.unblockUI();

// Hide all modals
modalSurface.hideAll();
```

## Parameters

<ResponseField name="isWideLayout" type="bool" required>
  Whether the app is in wide layout mode (affects modal sizing).
</ResponseField>

<ResponseField name="isCaregiverApp" type="bool" required>
  Whether this is the caregiver app variant.
</ResponseField>

<ResponseField name="child" type="Widget" required>
  The app content to wrap.
</ResponseField>

## Best Practices

<Warning>
Don't create multiple ModalSurface instances. Use a single instance at the app root.
</Warning>

```dart
// ✅ GOOD - Single ModalSurface at root
MaterialApp(
  home: ModalSurface(
    isWideLayout: isWide,
    child: MyApp(),
  ),
)

// ❌ BAD - Multiple instances
ModalSurface(
  child: Scaffold(
    body: ModalSurface( // Don't nest!
      child: Content(),
    ),
  ),
)
```
