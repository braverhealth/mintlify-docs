Text color tokens provide consistent typography colors with automatic light/dark mode adaptation. These tokens ensure readable text across all surfaces.

## Accessing Text Colors

```dart
final colors = context.getColors();

// Primary text (full contrast)
final primary = colors.text;

// Pale text (reduced emphasis)
final pale = colors.textPale;

// Extra pale text (subtle)
final xpale = colors.textXPale;
```

## Usage Examples

### Primary Text

```dart
NormalText(
  'Main content text',
  color: TextColor.initial,  // Uses colors.text
)
```

### Secondary Text (Pale)

```dart
NormalText(
  'Supporting information',
  color: TextColor.pale,  // Uses colors.textPale
)
```

### Subtle Text (XPale)

```dart
NormalText(
  'Metadata or hints',
  color: TextColor.xpale,  // Uses colors.textXPale
)
```

### Error Text

```dart
NormalText(
  'Invalid input',
  color: TextColor.invalid,  // Uses colors.textInvalid
)
```

### Tinted Text

```dart
NormalText(
  'Highlighted action',
  color: TextColor.tint,  // Uses colors.tintTextPrimary
)
```

## TextColor Enum

The `TextColor` enum maps to these tokens:

```dart
enum TextColor {
  initial,      // colors.text
  pale,         // colors.textPale
  xpale,        // colors.textXPale
  xxpale,       // colors.textXXPale
  tint,         // colors.tintTextPrimary
  secondaryTint,// colors.tintTextSecondary
  invalid,      // colors.textInvalid
  unavailable,  // Special state
  white,        // Pure white
  primary,      // Primary action color
}
```

## Typography Hierarchy

Use text colors to create visual hierarchy:

| Level | Color | Use Case |
|-------|-------|----------|
| Primary | `text` | Main content, headings |
| Secondary | `textPale` | Descriptions, subtitles |
| Tertiary | `textXPale` | Metadata, timestamps |
| Subtle | `textXXPale` | Disabled, placeholders |
