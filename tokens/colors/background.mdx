Background color tokens define the visual hierarchy of surfaces throughout the application. All background colors are adaptive, meaning they automatically adjust for light and dark modes.

## Accessing Background Colors

```dart
final colors = context.getColors();

// Primary background (main content areas)
final primary = colors.backgroundPrimary;

// Secondary background (cards, sections)
final secondary = colors.backgroundSecondary;

// Tertiary background (nested containers)
final tertiary = colors.backgroundTertiary;
```

## Usage Examples

### Card Container

```dart
Container(
  color: colors.backgroundSecondary,
  child: CardContent(),
)
```

### Nested Section

```dart
Container(
  color: colors.backgroundTertiary,
  child: NestedContent(),
)
```

### Error State Background

```dart
Container(
  color: colors.backgroundInvalid,
  child: ErrorContent(),
)
```

### Transparent Background

```dart
Container(
  color: colors.backgroundSecondaryTransparent,
  child: OverlayContent(),
)
```

## Forcing Brightness

Override the automatic brightness detection:

```dart
// Force light mode colors
final lightColors = context.getColors(light: true);

// Force dark mode colors
final darkColors = context.getColors(dark: true);
```

## Visual Hierarchy

The background color hierarchy creates depth:

1. **Primary** - Main content surface
2. **Secondary** - Elevated cards and sections
3. **Tertiary** - Nested elements within cards
4. **Quaternary** - Deeply nested elements

```dart
Container(
  color: colors.backgroundPrimary,  // Outermost
  child: Container(
    color: colors.backgroundSecondary,  // Card level
    child: Container(
      color: colors.backgroundTertiary,  // Nested section
      child: Content(),
    ),
  ),
)
```
