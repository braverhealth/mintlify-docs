Colors are organized into semantic categories. Most colors are **adaptive**, automatically adjusting for light and dark modes.

## Accessing Colors

```dart
// Access via context extension
final colors = context.getColors();

// Use semantic color getters
Container(
  color: colors.backgroundPrimary,
  child: Text(
    'Hello',
    style: TextStyle(color: colors.text),
  ),
)
```

### Forcing Brightness

```dart
// Force dark mode colors
final darkColors = context.getColors(dark: true);

// Force light mode colors
final lightColors = context.getColors(light: true);

// Invert current mode
final invertedColors = context.getColors(invert: true);
```

## All Color Tokens

### Background Colors

| Token | Description | Adaptive |
|-------|-------------|----------|
| `backgroundPrimary` | Main background | ✅ |
| `backgroundSecondary` | Secondary surfaces | ✅ |
| `backgroundTertiary` | Tertiary surfaces | ✅ |
| `backgroundQuaternary` | Deepest level | ✅ |
| `backgroundInvalid` | Error state backgrounds | ✅ |
| `backgroundHighlight` | Selection highlight | ✅ |
| `backgroundEmpty` | Empty state backgrounds | ✅ |

### Text Colors

| Token | Description | Adaptive |
|-------|-------------|----------|

| `textXXPale` | Disabled text | ✅ |
| `textInvalid` | Error text | ✅ |
