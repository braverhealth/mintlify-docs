Tint color tokens provide brand accent colors used for interactive elements, highlights, and visual emphasis. These colors create the distinctive Braver visual identity.

## Accessing Tint Colors

```dart
final colors = context.getColors();

// Primary tint (main brand color)
final primary = colors.tintPrimary;

// Secondary tint (complementary accent)
final secondary = colors.tintSecondary;

// Tertiary tint (subtle accent)
final tertiary = colors.tintTertiary;
```

## Usage Examples

### Interactive Elements

```dart
Container(
  decoration: BoxDecoration(
    color: colors.tintPrimary,
    borderRadius: BorderRadius.circular(8),
  ),
  child: Text('Selected', style: TextStyle(color: Colors.white)),
)
```

### Selection State

```dart
Container(
  color: isSelected ? colors.tintPrimary : colors.backgroundSecondary,
  child: ListItem(...),
)
```

### Accent Background

```dart
Container(
  color: colors.tintTertiaryBackground,
  child: HighlightedContent(),
)
```

### Tinted Text

```dart
NormalText(
  'View details',
  color: TextColor.tint,  // Uses tintTextPrimary
)
```

## Button Tints

Buttons use tint colors for their different states:

```dart
PrimaryButton(
  text: 'Submit',
  tint: PrimaryButtonTint.primary,  // tintPrimary
  onPressed: () => submit(),
)

PrimaryButton(
  text: 'Secondary Action',
  tint: PrimaryButtonTint.secondary,  // tintSecondary
  onPressed: () => action(),
)
```

## Special Colors

### Grey Transparent

```dart
// Semi-transparent overlay
Container(
  color: colors.greyTransparent,
  child: OverlayContent(),
)
```

## Adaptive Behavior

Tint colors adapt to brightness while maintaining brand consistency:

```dart
// In light mode: vibrant purple
// In dark mode: slightly adjusted for dark backgrounds
final tint = colors.tintPrimary;
```

## Use Cases

| Use Case | Token |

| Subtle highlights | `tintTertiaryBackground` |
