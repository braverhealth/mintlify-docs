Border color tokens define colors for outlines, separators, and visual boundaries. These tokens ensure consistent borders across the application.

## Accessing Border Colors

```dart
final colors = context.getColors();

// Standard border
final border = colors.border;

// Pale border (subtle)
final pale = colors.borderPale;

// Heavy border (emphasized)
final heavy = colors.borderHeavy;
```

## Usage Examples

### Standard Border

```dart
Container(
  decoration: BoxDecoration(
    border: Border.all(color: colors.border),
    borderRadius: BorderRadius.circular(8),
  ),
  child: Content(),
)
```

### Subtle Border

```dart
Container(
  decoration: BoxDecoration(
    border: Border.all(color: colors.borderPale),
    borderRadius: BorderRadius.circular(12),
  ),
  child: CardContent(),
)
```

### Emphasized Border

```dart
Container(
  decoration: BoxDecoration(
    border: Border.all(color: colors.borderHeavy, width: 2),
    borderRadius: BorderRadius.circular(8),
  ),
  child: FocusedContent(),
)
```

### Divider Line

```dart
Container(
  height: 1,
  color: colors.border,
)
```

### List Separator

```dart
ListView.separated(
  itemBuilder: (context, index) => ListItem(...),
  separatorBuilder: (context, index) => Divider(
    color: colors.borderPale,
    height: 1,
  ),
  itemCount: items.length,
)
```

## Navigation Bar Separator

```dart
Container(
  decoration: BoxDecoration(
    border: Border(
      bottom: BorderSide(color: colors.separatorNavBar),
    ),
  ),
  child: NavBar(),
)
```

## Selection Border

Use heavier borders for selected states:

```dart
Container(
  decoration: BoxDecoration(
    border: Border.all(
      color: isSelected ? colors.tintPrimary : colors.borderPale,
      width: isSelected ? 2 : 1,
    ),
    borderRadius: BorderRadius.circular(8),
  ),
  child: SelectableItem(),
)
```

## Border Hierarchy

| Level | Token | Use Case |
|-------|-------|----------|
| Subtle | `borderPale` | Cards, sections |
| Standard | `border` | Form inputs, containers |
| Emphasized | `borderHeavy` | Focus states, emphasis |
