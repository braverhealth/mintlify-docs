title: Accent Colors
description: Semantic accent colors for status, avatars, and special states
---

Accent colors provide semantic meaning through color - success, warning, error, and decorative purposes like avatars.

## Accessing Accent Colors

```dart
final colors = context.getColors();

// Status colors (from swatch)
final success = Color(colors.swatchGreen900);
final warning = Color(colors.swatchOrange900);

// Avatar colors
final avatarColors = [
  Color(colors.avatar1),
  Color(colors.avatar2),
  // ... through avatar8
];
```

## Usage Examples

### Success State

```dart
Container(
  decoration: BoxDecoration(
    color: Color(colors.swatchGreen700),
    borderRadius: BorderRadius.circular(4),
  ),
  child: Text('Success', style: TextStyle(color: Colors.white)),
)
```

### Warning/Error State

```dart
Container(
  decoration: BoxDecoration(
    color: Color(colors.swatchOrange700),
    borderRadius: BorderRadius.circular(4),
  ),
  child: Text('Warning', style: TextStyle(color: Colors.white)),
)
```

### Avatar Background

```dart
// Get avatar color based on user's color index
final avatarColor = Color(colors.avatarColorAt(userColorIndex));

CircleAvatar(
  backgroundColor: avatarColor,
  child: Text(initials),
)
```

### Availability Indicator

```dart
Container(
  width: 8,
  height: 8,
  decoration: BoxDecoration(
    color: Color(colors.availabilityYellow),
    shape: BoxShape.circle,
  ),
)
```

## Button Tints

Semantic colors are used in button tints:

```dart
// Primary action
PrimaryButton(
  text: 'Submit',
  tint: PrimaryButtonTint.primary,
  onPressed: () => submit(),
)

// Destructive action (orange)
PrimaryButton(
  text: 'Delete',
  tint: PrimaryButtonTint.warning,
  onPressed: () => delete(),
)

// Success confirmation
PrimaryButton(
  text: 'Confirm',
  tint: PrimaryButtonTint.success,
  onPressed: () => confirm(),
)
```

## MenuButton Variants

```dart
// Destructive menu action
MenuButton.invalid(
  text: 'Delete',
  iconName: SvgIconName.trash,
  onPressed: () => delete(),
)
```

## Avatar Color Selection

Avatar colors are assigned based on a user's color index:

```dart
class AvatarSubject {
  final int colorIndex;  // 0-7, maps to avatar1-avatar8
  final String initials;
}
```

## Semantic Color Guidelines

| Semantic | Color | Use Case |
|----------|-------|----------|
| Success | Green | Confirmations, completed states |
| Warning | Orange | Destructive actions, alerts |
| Info | Tint Primary | Information, highlights |
| Neutral | Grey | Disabled, unavailable |
